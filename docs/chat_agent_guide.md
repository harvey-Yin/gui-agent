# 对话式Agent使用指南

## 快速开始

### 1. 启动服务

```powershell
# 启动MAI-UI-2B
cd c:\document\python\gui-agent
docker-compose up -d

# 启动Ollama
ollama serve
```

### 2. 运行对话Agent

```powershell
python demo_chat_agent.py
```

## 使用方式

### 纯聊天
```
你: 你好，你能做什么？
Agent: 你好！我是一个智能RPA助手...
```

### 执行任务
```
你: 帮我打开WPS
Agent: 好的，我来帮你打开WPS文字
   💭 思考: 用户需要打开WPS应用
   🎯 操作: open_wps {}
   ❓ 是否执行此操作？(y/n): y
   ✅ WPS已启动
```

### 视觉识别
```
你: 看一下当前屏幕有什么
Agent: 我来查看屏幕
   💭 思考: 使用MAI-UI-2B分析屏幕
   🎯 操作: look_screen {}
   ❓ 是否执行此操作？(y/n): y
   👁️  视觉分析:
      应用: WPS
      状态: IN_PROGRESS
      建议: 可以开始输入内容
```

### 复杂任务
```
你: 帮我根据北京的天气生成一篇文章并保存到WPS

Agent会自动分解为多个步骤：
1. 获取天气
2. 生成文章
3. 打开WPS（如果未打开）
4. 写入内容
5. 保存文档
```

## 示例对话

### 示例1：天气文章任务

```
你: 你好
Agent: 你好！我是你的RPA助手，可以帮你操作电脑。有什么我能帮你的吗？

你: 帮我获取一下北京的天气
Agent: 好的，我来获取北京的天气信息
   💭 思考: 调用天气API获取数据
   🎯 操作: get_weather {"city": "Beijing"}
   ❓ 是否执行？(y/n): y
   ✅ 天气: 15°C, Partly cloudy
   📊 天气数据已保存

你: 根据这个天气生成一篇200字的播报文章
Agent: 好的，我来生成天气播报文章
   💭 思考: 使用已保存的天气数据生成文章
   🎯 操作: generate_article {"prompt": "..."}
   ❓ 是否执行？(y/n): y
   ✅ 文章已生成 (203 字)
   📝 文章已生成

你: 帮我把文章保存到WPS
Agent: 好的，我先查看一下屏幕
   [执行 look_screen]
   [发现WPS未打开]
   
Agent: 我需要先打开WPS
   [执行 open_wps]
   [执行 paste_text]
   [执行 hotkey ctrl+s]
   
Agent: 文章已保存到WPS文档中！
```

### 示例2：屏幕分析

```
你: 看看我的屏幕上有什么

   👁️  视觉分析:
```

### 聊天类
- "你好"
- "你能做什么？"
- "介绍一下你自己"

### 视觉类
- "看一下屏幕"
- "当前屏幕有什么？"
- "WPS打开了吗？"

### 操作类
- "打开WPS"
- "点击屏幕中央"
- "按Ctrl+S"
- "输入XXX"

### 数据类
- "获取北京天气"
- "生成一篇文章"

### 任务类
- "帮我根据天气生成文章并保存到WPS"
- "打开WPS并创建一个新文档"

## 特性

### 1. 自然对话
- 可以像和人聊天一样交流
- AI会理解你的意图

### 2. 任务分解
- 复杂任务自动分解为多个步骤
- 逐步执行并报告进度

### 3. 视觉感知
- 使用MAI-UI-2B查看屏幕
- 智能识别界面状态

### 4. 安全确认
- 执行操作前需要确认
- 防止误操作

### 5. 上下文记忆
- 记住对话历史
- 保存任务数据（天气、文章等）

## 技术架构

```
用户输入
   ↓
ConversationalAgent
   ├─ 理解意图（qwen）
   ├─ 决定是对话还是操作
   │
   ├─ 如果是对话 → 直接回复
   │
   └─ 如果是操作
       ├─ 生成操作计划
       ├─ 请求用户确认
       └─ 执行操作
           ├─ VisionModule（视觉）
           └─ ActionModule（执行）
```

## 优势

### vs 固定Agent
- ✅ **灵活**: 不限定任务，随时改变
- ✅ **交互**: 可以对话，可以提问
- ✅ **可控**: 每步都需确认

### vs 纯聊天机器人
- ✅ **能干活**: 真的能操作电脑
- ✅ **有眼睛**: 能看屏幕
- ✅ **有手**: 能点击、输入

## 注意事项

1. **确认操作**: 每次操作都会询问，输入`y`确认
2. **任务数据**: 天气、文章等数据会自动保存，可以复用
3. **视觉识别**: 需要MAI-UI-2B Docker运行
4. **推理能力**: 需要Ollama qwen运行
